# Claude Code VS Code Setup

為 VS Code 裡的 Claude Code 加上提示音，讓你不用盯著螢幕等。

Add notification sounds to Claude Code in VS Code — so you know exactly when to look back at your screen.

---

## 這是什麼？/ What is this?

用 Claude Code（VS Code 擴充套件版）開發時，常會遇到兩種情境需要你切換回畫面：

1. **Claude 執行完畢** — 任務跑完了，可以看結果了
2. **Claude 需要你操作** — 執行到一半，等你按確認或做下一步

這個 repo 提供的設定，會在這兩個時機自動觸發提示音，讓你專心做其他事，聽到聲音再回來就好。

---

When using Claude Code (VS Code extension), there are two moments you need to switch back:

1. **Claude finishes a task** — ready for you to review the result
2. **Claude needs your input** — waiting for you to confirm or take the next step

This repo sets up notification sounds that trigger at exactly those moments, so you can focus elsewhere and only return when you hear the alert.
